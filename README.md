# 🐼 Panda's Magical Birthday World — Queen Ashitha's Royal Celebration 🎂👑

A fully interactive, cinematic 3D web application created for Queen Ashitha's royal birthday celebration. Built using **Streamlit** and **Three.js**, featuring custom 3D low-poly models, interactive quests, ambient Tamil birthday melody, realistic lighting, and cinematic celebrations.

---

## 🌟 Stages & Features

1. **🌸 Stage 1 — Panda Village Welcome**
   - Enchanting blossom forest with friendly panda villagers, warm ambient lighting, and welcoming interactions.
2. **🧩 Stage 2 — Memory & Friendship Quiz**
   - Thoughtful interactive question challenges celebrating favorite memories.
3. **🚪 Stage 3 — Ancient Gate & 10 Magical Gifts**
   - The grand gateway to the hidden realm and reveal of 10 special birthday gifts.
4. **🌿 Stage 4 — Whispering Woods & The Golden Key**
   - Nature pathway with flying storks, flamingos, and searching for the secret Golden Key.
5. **🏰 Stage 5 — The Royal Panda Kingdom & Final Surprise**
   - Magnificent grand courtyard with a royal purple carpet and twin thrones.
   - **Royal Treasure Chest**: Click the chest to trigger the secret question (*"What does your favourite person call you most of the time?"* -> **Papa**).
   - **3D Diamond Ring Reveal**: A floating, rotating gold ring with a sparkling diamond in a velvet cavity.
   - **Royal Walk & Celebration**: King Panda Mama and Queen Panda Ashitha hug, walk hand-in-paw to the thrones, and pandas celebrate with fireworks and floating hearts.
   - **Cinematic Celebration Video**: 16:9 cinematic video featuring the royal celebration with the Tamil birthday song (*"அழகான நிலவே"*).

## 🚀 Running Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/mistery-but-fun/birthday-gift.git
   cd birthday-gift
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```

4. Open your browser at `http://localhost:8501`.

---

## ☁️ Deploying on Streamlit Community Cloud

1. Visit [share.streamlit.io](https://share.streamlit.io) and sign in with GitHub.
2. Click **"New app"** and select:
   - **Repository:** `mistery-but-fun/birthday-gift`
   - **Branch:** `main`
   - **Main file path:** `app.py`
3. Click **Deploy!**
